Tính năng nổi bật
Dữ liệu thời gian thực: Kết nối OpenWeatherMap API chính xác.
Giao diện hiện đại: Thiết kế Glassmorphism và hiệu ứng Gradient động theo thời tiết.
Tìm kiếm thông minh: Thanh tìm kiếm luôn hiển thị, hỗ trợ tìm kiếm mọi thành phố.
Định vị GPS: Tự động lấy thời tiết tại vị trí hiện tại.

Công nghệ sử dụng
Ngôn ngữ: Java & XML (Android SDK).
hư viện: Retrofit 2 (Networking), Picasso (Image Loading), Lottie (Animation).
Kiến trúc: ViewBinding.

## Cấu trúc thư mục sạch
`app/`: Chứa toàn bộ mã nguồn và tài nguyên giao diện.
`apk/`: Chứa file cài đặt dùng thử.
`SS/`: Hình ảnh và video minh họa dự án.
